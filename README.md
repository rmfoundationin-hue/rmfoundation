# Raj Maurya Foundation Website

यह एक static, responsive website है जो उपलब्ध Raj Maurya Foundation के दस्तावेज़ और आपके दिए गए फोटो/लोगो के आधार पर तैयार की गई है।

## Files
- index.html — मुख्य वेबसाइट
- style.css — पूरा responsive design
- script.js — mobile menu और contact form behavior
- assets/ — उपलब्ध कराए गए logo/photos

## Run
index.html पर double-click करके browser में खोलें या किसी static hosting (Netlify, GitHub Pages, Cloudflare Pages आदि) पर upload करें।

## Important
- वेबसाइट में Aadhaar/ID जैसी निजी पहचान जानकारी प्रकाशित नहीं की गई है।
- Contact form अभी demo है; official email/WhatsApp/phone मिलने पर इसे live action से जोड़ा जा सकता है।
- संस्था की गतिविधियों के लिए source में उपलब्ध जानकारी ही इस्तेमाल की गई है।
